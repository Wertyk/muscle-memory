This is a small screening benchmark, not a production reliability or pricing study. Ten short, independent calls cannot establish multi-step agent reliability. Output caps may penalize reasoning models. Latency includes network and provider load. Token counts do not establish monetary cost without per-model prices.

Total benchmark usage: **31,988 tokens**, across 60 requests. The date above is UTC (2026-11-02 in Moscow).

Recommended main model: **`deepseek-v4-pro:0813`**. It was the fastest main candidate with 10/10 correct calls (952 ms mean). `kimi-k3` and `glm-5.3` also passed all cases and used fewer tokens, at higher observed latency. `gpt-oss:120b` was faster but failed exact arguments on two cases. This selects for observed correctness and responsiveness; compare provider prices before claiming a monetary saving.

Recommended cheap extraction model: **`glm-5.3-flash`**. It passed 10/10 tool cases versus 8/10 for `gpt-oss:20b`, with lower mean latency. It also passed the actual framework extraction smoke below. Only one extraction fixture was run to limit spend; accuracy across real request types remains to be measured.
